Исходные машинные отчёты: `erc.json`, `drc.json`, `connectivity.json`, `spice.json`, `spice.log`, `export.log`. Нативная проверка соответствия включает связь UUID символов с посадочными местами, значения, имена цепей и исключение тестовых площадок из BOM. Независимая проверка сравнивает пары reference/pin; при этом удаляется только корневой префикс `/` имён цепей.

Запуск ngspice выполнен через shared library из KiCad; отсутствие необязательного файла `spinit` отмечено в логе, модель состоит только из штатных R/C и источника и успешно выполнила AC и transient. Сторонние модели не требовались.

Производственные экспорты получены непосредственно из финального CAD средствами KiCad CLI. Иллюстрации платы — 3D-рендер и SVG-экспорт KiCad, а не фотографии изделия. Программные проверки не заменяют изготовление и стендовые измерения.
